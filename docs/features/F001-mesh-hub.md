# F001 - Quant Strategy: 开源低频量化研究站

## 愿景

我们用确定性规则替代情绪化交易，以策略确定性应对市场与人性的双重不确定性，为没有时间盯盘的投资者提供收益靠谱、回撤可控的自动化策略参考。

## 背景

铲屎官已有一套经过实盘验证的 TrendLock 40（BTC 4H MA240 + 4D，内部代号 T40-4）策略（运行在 OKX 上），希望：
1. 将策略研究过程和成果公开分享
2. 代码完全开源，任何人可复现
3. 通过网站展示策略当前状态和历史回测
4. 不收费，通过捐赠支持项目（参考 Immich 模式）

## 参考

- [Arkvol](https://arkvol.com/)：数据分析工具平台，Freemium 模式。我们的定位与其不同——我们分享策略研究成果，不是提供工具。
- [Immich](https://github.com/immich-app/immich)：开源 + AGPL + Open Collective 捐赠模式。我们参考其运营方式。

## 策略规格

### TrendLock 40（BTC 4H MA240 + 4D）

| 参数 | 值 | 说明 |
|------|-----|------|
| 时间框架 | 4H | 4小时K线 |
| 均线周期 | MA240 | 240根4H线的简单移动平均线 |
| 最小持仓期 | 24根K线（4天） | 买入后至少持有4天才允许卖出 |
| 交易对 | BTC-USDT | — |
| 数据源 | OKX 公开API | 无需认证，免费 |

**买入条件**（交叉确认）：
- 前一根K线收盘价 ≤ 前一根K线的MA240
- 当前K线收盘价 > 当前K线的MA240

**卖出条件**（跌破即卖，非对称设计）：
- 持仓满24根K线（4天）后
- 当前K线收盘价 < 当前K线的MA240

**设计要点**：
- 入场严格（需要交叉确认），出场灵敏（单点跌破即可）
- 只使用已确认闭合的K线（confirm==1），避免未完成K线的噪音
- 无止损、无止盈、无加仓、不做空

## 产品规格

### 网站功能

1. **首页**：项目介绍 + 策略列表 + 捐赠入口
2. **策略状态页** `/strategy/btc-ma240-4d`：
   - 当前信号状态（持仓/空仓）
   - 当前价格 vs MA240 值
   - 持仓时长（如适用）
   - 最近一次信号的时间和原因
3. **回测展示页** `/backtest/btc-ma240-4d`：
   - 收益率曲线图
   - 价格 + MA240 + 买卖点标注图
   - 关键指标：总收益率、最大回撤、胜率、夏普比率、交易次数
   - 与 Buy & Hold 的对比
   - 完整交易记录表
4. **免责声明页** `/disclaimer`：
   - "不提供投资建议"
   - "仅限研究目的"
   - "历史表现不代表未来收益"
   - 数据源、延迟、手续费假设说明

## 技术架构

```
┌─────────────────────────────────────────────┐

│  site/         ← 前端代码 (MIT)              │
│  data/         ← 策略结果JSON（git tracked）  │
└──────────────┬──────────────────────────────┘
               │ GitHub Actions (每4H cron)
               ▼
┌──────────────────────┐    ┌─────────────────┐
│ OKX 公开API          │───▶│ Python pipeline  │
│ (无需认证，免费)      │    │ → 拉取4H K线     │
└──────────────────────┘    │ → 计算MA信号      │
                            │ → 跑回测          │
                            │ → 生成JSON+PNG    │
                            └────────┬──────────┘
                                     │ git commit & push
                                     ▼
                            ┌─────────────────┐
                            │ Vercel (免费)    │
                            │ 静态站 (SSG)     │
                            │ quant-strategy.  │
                            │ mesh-hub.xyz     │
                            └─────────────────┘
```

### 关键设计决策

| 决策 | 选择 | 理由 |
|------|------|------|
| 策略语言 | Python | 铲屎官已有Python脚本，量化生态最成熟 |
| 数据管道 | GitHub Actions (4H cron) | 零运维成本，免费2000分钟/月 |
| 前端 | Astro + React | SSG快，React做交互图表 |
| 部署 | Vercel (Hobby免费) | 自动部署，全球CDN |
| 数据存储 | JSON in Git | 零成本，不可篡改历史记录 |
| 策略代码许可 | AGPL-3.0 | 保护核心不被闭源商用 |
| 网站代码许可 | MIT | 最大程度被社区复用 |
| 美股数据（MSTR） | 只展示派生研究结果 | 避免原始行情数据再分发合规问题 |

## 合规边界

1. **定位**：开源量化研究实验室，不是投资顾问
2. **所有内容免费公开**，不设付费门槛
3. **策略状态和信号作为知识分享**，明确标注"非投资建议"
4. **代码开源**，用户可以自行验证和复现
5. **捐赠支持项目开发**，不是"付费买信号"
6. **美股数据不原样再分发**，只展示派生分析结果
